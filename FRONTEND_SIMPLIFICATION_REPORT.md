## 2. Unnecessary Content Removed or Relocated

### Content Removed from Normal Interface:
1. **Local Machine & Storage Telemetry:** Completely removed drive letters (`Drive E:`), free disk space (`11.47 GB free`), and disk quota warnings.
2. **Repository Audit Counters:** Removed raw ingestion totals ("679 verified images, 0 corrupt") from the primary dashboard.
3. **Internal Pipeline Phase Numbers:** Removed developer milestone badges ("Phase 1: Ingestion", "Phase 2: Preprocess", "Phase 3: CNN Training", "Phase 4: Grad-CAM").
4. **Technical Headline Clutter:** Removed library and framework names (e.g., PyTorch, ResNet-50) from prominent headlines, keeping them in secondary technical captions only.
5. **Raw Filename Headlines:** Replaced prominent technical file paths with clean filenames as secondary metadata.
6. **Competing Upload & Sample Boxes:** Eliminated multi-card sample grids surrounding the dropzone; replaced with an optional "Try a Verified Sample" drawer.
7. **Generic AI Fluff:** Removed empty status cards, fake decorative charts, and marketing filler text.

### Content Relocated:
- **Technical Model Architecture & Benchmark Metrics:** Relocated to a clean, collapsible accordion ("Technical Details & Validation Benchmark") in `AboutPage.tsx` and `ResultsPage.tsx`, allowing researchers to review held-out test accuracy (66.7% mammogram, 25.0% thermal) without overwhelming standard users.
- **Dataset Provenance & Ethics Notices:** Moved to the **About** section.

## 3. Design and Usability Changes

1. **Streamlined 5-Item Navigation:**
   - **Home (`#home`):** Short explanation, two prominent action cards ("Analyze a Mammogram" and "Analyze a Thermal Image"), system readiness pill, and medical disclaimer.
   - **New Analysis (`#analyze`):** Modality toggle (Mammogram vs Thermal), drag-and-drop upload, image preview, replace/remove buttons, and primary "Run Analysis" button.
   - **Results (`#results`):** Predicted classification (Normal / Benign / Malignant), confidence percentage, Grad-CAM saliency comparison, and "Start a New Analysis" action.
   - **Analysis History (`#history`):** Real session analysis records from `/api/recent-analyses`.
   - **About & Disclaimer (`#about`):** Research scope, cohort boundaries, dataset citations, and optional technical validation metrics.
2. **Backward Compatible Hash Navigation:** Existing bookmarks to legacy routes (`#overview`, `#mammogram`, `#thermal`, `#explainability`, `#datasets`, `#evaluation`) automatically redirect to their modern unified equivalents without 404 errors.
3. **Restrained Luxury Aesthetic:**
   - Warm Ivory background (`#FAF7F2`) with crisp white elevated surfaces (`#FFFFFF`).
   - Primary buttons in muted Rose Gold (`#B23B55`) with high contrast white text.
   - Deep velvet plum text (`#2C1820`) ensuring WCAG AAA legibility.
   - Zero neon colors, heavy gradients, or excessive glassmorphic effects.
4. **Intuitive Image Management:**
   - Drag & drop dropzone with immediate file extension verification (`.png`, `.jpg`, `.jpeg`, `.pgm`) and 25 MB limit guarding.
   - Live image preview with aspect-ratio containment and optional quick filters (Invert Polarity, Contrast Boost).
   - Instant "Replace" and "Remove" actions with automatic browser memory cleanup (`URL.revokeObjectURL`).

## 4. Features Confirmed Working

- **Single-Page Application Hash Routing:** Fast, smooth navigation across all 5 views with browser back/forward and refresh state persistence.
- **Image Upload & Validation:** Verified with drag-and-drop and file browser for PNG, JPG, and PGM files.

- **Real Grad-CAM Heatmap Generation:** Grad-CAM overlays generated dynamically on the server from ResNet-50 `layer4` feature activations and displayed in the Results view.

- **Backend Connection Health:** Status indicator updates in real-time based on `GET /api/status`.

## 5. Features Unavailable or Represented Honestly

- **Multimodal Paired Analysis:** Not supported. Unpaired synthetic multimodal cross-pairing is strictly prohibited by scientific integrity policy because MIAS (mammograms) and Mendeley (thermograms) are distinct patient cohorts. The UI presents each modality independently.
- **Unconnected Model Fallback:** If model weights are removed or unavailable, the UI disables the "Run Analysis" button and clearly displays: *"Analysis is not available yet because a trained model has not been connected."*
- **No Diagnostic Claims:** All predictions are clearly labeled as model outputs and accompanied by the mandatory disclaimer:
  > *"This research prototype is not a medical diagnosis. It must not be used to make healthcare decisions. Please consult a qualified healthcare professional."*

## 8. Remaining Issues & Notes

1. **Uncompressed PGM Rendering in Pure Browser Canvas:**
   - Raw `.pgm` files (from the MIAS archive) are greyscale binary raster maps not natively rendered by browser `<img>` tags. The application gracefully handles this by displaying a clear notification banner with the file metadata, transmitting the binary to the server, and rendering the decoded PNG and Grad-CAM in the Results view.
2. **Raw Thermogram Calibration:**
   - Mendeley thermal images lack ambient camera calibration curves, leading to a baseline ResNet-50 test accuracy of 25.0%. This limitation is honestly disclosed in the Technical Benchmark section of `AboutPage.tsx`.
